# Monopoly (Java)

This is a rewrite of my 1st year Monopoly project. I rebuilt it with enhancements to have a project that is up to a higher standard to strengthen my Java fundamentals and OOP design before starting 2nd year.

It was built as coursework for Cardiff University.

## Features
- Configurable board sizes and player counts
- Full Monopoly ruleset (property trading, rent, bankruptcy, station teleports, cycle squares)
- Object-oriented architecture 

## Tech Stack
- Java
- JUnit (for unit testing)

## How to run
`gradlew run`

## How to test
`gradlew test`
